# 周期研究：《涛动周期论》四周期嵌套法与 2026 年后周期推演

| 文件 | 说明 |
| --- | --- |
| `涛动周期论_学习笔记与预测报告.md` | 理论要点、判断方法、最新数据、未来数年预测（正文） |
| `涛动周期论_周期预测.py` | 预测程序，PyCharm 直接运行；内置 2026-09 数据，可在运行时交互覆盖 |
| `宏观数据_2026-09.csv` | 程序内置的 52 条宏观指标及来源 |
| `图1_四周期嵌套示意图.png` | 康波 / 房地产 / 中周期 / 库存 / 商品超级周期的历史拐点与推演 |
| `图2_2026-2032预测时间轴.png` | 各周期 2026-2032 的阶段划分与共振窗口 |
| `图3_周期定位仪表板.png` | 当前指标与周金涛式判断阈值的对照 |
| `美国涛动周期_预测报告.md` | 美国模型：康波与利率长波、房地产、中周期、库存周期的定位与 2026-2036 推演 |
| `美国涛动周期模型.py` | 美国模型程序，内置 47 条美国数据，含 1999-2003 类比与三情景 |
| `美国宏观数据_2026-09.csv` | 美国程序内置的数据及来源 |
| `图4_美国四周期嵌套示意图.png` | 美国 1980-2036 四周期与利率长波、共振分 |
| `图5_美国2026-2032预测时间轴.png` | 美国各周期、联储利率、美股的推演时间轴 |
| `图6_美国周期定位仪表板.png` | 美国指标与判断阈值的对照 |

运行依赖：`pandas`、`numpy`、`matplotlib`。程序不联网，更新数据只需修改第 2 步的数字。
