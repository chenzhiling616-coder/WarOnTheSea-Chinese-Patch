【简介 / About】

这是一个由玩家制作、完全免费的《War on the Sea》简体中文本地化补
丁。补丁覆盖游戏全部界面与文本：菜单、选项、战斗 HUD、信息日志、
损管界面、战役剧情、87 篇教程任务、40 个历史海战简介，以及识别手
册中 93 型舰船与飞机的级名、同级舰名、武器与挂载名称。

This is a free, fan-made Simplified Chinese localization patch for
War on the Sea. It covers virtually all in-game text: menus, options,
combat HUD, message log, damage control screens, campaign briefings
and events, all 87 tutorial pages, 40 historical battle descriptions,
and the Recognition Manual — class names, ship names, weapons and
payloads for all 93 ship/aircraft types.

【使用方法 / How to Use】

  1. 解压压缩包到任意位置
  2. 双击「中文补丁安装器.bat」
  3. 点击「汉化为简体中文」——完成！
     （随时可点「还原为初始状态」恢复英文原版）

  1. Extract the archive anywhere
  2. Double-click "中文补丁安装器.bat" (the installer)
  3. Click the green button to install Chinese — done!
     (Click the red button anytime to restore the original English)

【技术说明 / Technical Notes】

本补丁使用游戏内置的 override 模组目录与语言加载机制，不修改、
不覆盖任何游戏原版文件：

  StreamingAssets\override\language\chinese\  ← 268 个翻译文本
  StreamingAssets\override\config.txt         ← 语言设为 chinese

因此：存档完全兼容；游戏更新不会损坏补丁；删除 override 文件夹
即可彻底还原；与成就、多人功能无任何冲突。中文通过 Unity 动态
字体回退渲染（系统微软雅黑），属正常机制。

This patch uses the game's built-in "override" mod folder and
language-loading system. It does NOT modify or replace any original
game file. Saves remain fully compatible, game updates won't break
the patch, and deleting the override folder restores everything.
Chinese glyphs render through Unity's dynamic-font OS fallback
(Microsoft YaHei) — this is standard engine behavior.
